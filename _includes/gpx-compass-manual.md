# GPX Compass 操作マニュアル

Android・iOS共通 / 日本語版

更新日：2026-10-07

GPX Compassは、用意したGPXルートを見ながら走るためのナビゲーション補助アプリです。このマニュアルは、地図画面の表示の意味、各ボタンの操作、メニューの全項目を説明します。初めての利用には、アプリ内の「このアプリについて → 使い方」から開けるクイックスタートガイドも利用できます。

説明は2026-10-07時点の0.97.1系のAndroid・iOS実装に基づきます。画面例の数字は説明用です。ストア配信版と開発版では、利用できる項目や操作が異なる場合があります。距離リングの新しい太さ選択など、提出済み0.97.1の後に変更された操作には個別に注記しています。端末のバージョンは「このアプリについて」で確認してください。

メニュー名は主にAndroidの日本語表記を使い、iOSで異なる名前や動作を併記します。特記のない説明は両OS共通です。設定やルート切替は、安全に停止してから操作してください。

## 1. ルート案内・目的地ナビ・走行記録の違い

| 機能 | 何をするか | 開始する場所 |
| --- | --- | --- |
| GPXルート案内 | GPXに記録された道筋を表示し、ルート上の進捗、次のターン、逸脱・復帰を知らせる | 「ルート」で保存ルートを選び、詳細から「ルート走行開始」 |
| 目的地ナビ | 現在地から指定地点までの道路経路を検索する | 「ナビ」、ルート詳細のスタート／ゴールへのナビ、地図アプリからの地点共有 |
| 走行記録 | 実際に走った軌跡・距離・時間を保存し、終了後にGPXとして共有できるようにする | メインメニュー下部の「記録開始」または「走行記録も開始」 |
| グループライド位置共有 | 仲間と最新位置を共有する | 「グループライド」で作成／参加 |

**案内と記録は別々に開始します。** GPX案内だけを開始しても、保存用の走行記録は開始されません。走行ログを残したい場合は「走行記録も開始」を押してください。GPXを使わず「記録開始」だけを押すと、フリー走行を記録できます。

GPXの読込・受信・詳細閲覧だけでは、そのルートの案内を開始しません。走行中に別ルートの詳細を開いても、明示的に走行開始を確定するまでは現在の案内を続けます。

GPXルート案内は、道路規制や通行可能性を判定する機能ではありません。青線が道路に重なっていても、現地の標識や道路状況を確認してください。通常のルート逸脱では、道路経路の再検索は自動開始しません。

位置共有は案内・記録から独立しています。案内や記録を終了しても、位置共有は続くため、止める場合は「グループライド」で共有を一時停止するか、退出／グループ終了を選びます。

## 2. 地図画面の全体と操作ボタン

縦画面では、上部にHUD（速度・時刻・進捗などの情報帯）、その下に地図、最下部に青い操作バーを表示します。横画面ではHUDと操作バーを左右に分け、中央を地図として使います。HUDは通常、カメラの切り欠きと反対側に配置されます。端末やウィンドウの寸法によって配置が変わり、情報が収まらない場合はスクロールできます。

### 2.1 青い操作バーの5つのボタン

| ボタン | 意味と操作 |
| --- | --- |
| メニュー（横3本線） | メインメニューを開く。メニュー表示中は地図へ戻るために使う |
| 地図の向き | ノースアップ（北が上）とヘディングアップ（進行方向が上）を切り替える |
| 現在地追従 | 現在地に地図を追従させるON／OFFを切り替える。OFFのときは状態色が変わり、任意の場所を見続けられる |
| − | 地図を縮小し、広い範囲を表示する |
| ＋ | 地図を拡大し、細かい位置関係を確認する |

縦画面ではメニュー側から上記の順に並びます。横画面の縦長操作バーでは、上から「＋、−、現在地追従、地図の向き、メニュー」の順です。

ノースアップでは自車の矢印が地図上で回転します。ヘディングアップでは地図が回転し、進行方向の先を広く表示します。画面の縦／横固定は別の設定で、「表示 → 画面の向き」から変更します。

### 2.2 指で地図を操作する

- ドラッグ：地図を移動します。
- ピンチ：地図を拡大／縮小します。地図エンジンの標準ジェスチャーも利用できます。
- 現在地追従ONのまま地図を動かす：指を離してから約5秒後に現在地へ戻ります。先の道を一時的に確認するのに使えます。
- 任意の場所を見続ける：現在地追従をOFFにします。ONに戻すと現在地へ追従します。

地図を動かしている間も、現在地は更新されます。画面を触っただけで走行記録や案内が停止することはありません。

### 2.3 条件によって出る表示

| 表示 | 意味・操作 |
| --- | --- |
| GPXルート走行開始 | GPXを地図に表示しているが案内を始めていない待機状態。押すと開始操作へ進む |
| 地図準備・圏外・利用不可などの状態 | 選んだ地図の準備中、地理院地図への退避、通信／地図エンジンの問題を示す。「地図」で表示ソースを確認する |
| オフライン地図の取得進捗 | 地図を保存中。HUDの進捗表示をタップすると準備状況を確認できる |
| 目的地の照準 | 「ナビ → 地図から選ぶ」で表示。地図を動かして照準に目的地を合わせ、「ここへナビ」で確定する |
| 目的地ナビの検索・失敗などの案内 | 経路の取得状態を示す。iOSでは案内がまだ開始されていないときなどに橙色の案内帯が出る。タップして「ナビ」を開く |
| ルート案内終了のサマリー | 案内区間の距離・時間などを示す。記録が続いている場合は継続中と表示される |
| 保存済みログの名前と閉じるボタン | 過去の走行ログを全画面で閲覧中。閉じるとログ詳細へ戻る |
| 著作権・出典表示 | Google、Apple、OpenStreetMap、国土地理院など、表示中の地図の出典。ルート名や通信状態とは別の表示 |

操作バーが隠れている場合の復帰は[表示メニュー](#display-menu)を参照してください。

## 3. HUDの各項目

HUDは半透明の暗い背景に大きな数字を表示する情報帯です。状態に必要な項目だけを表示するため、起動直後・フリー走行・GPX案内・目的地ナビでは内容が変わります。

### 3.1 速度

`42 kph`などの数字は、アプリが現在採用している速度です。`kph`はkm/hと同じ意味です。外部センサーを使用している場合も、この欄には採用された速度を表示します。

- `0`：有効な速度情報があり、停止しています。
- `--`：表示できる速度情報がありません。
- 数字は整数に丸めて表示します。車両の速度計とは測定方法が異なり、差が出ることがあります。

速度表示は常時表示です。現行の通常版には速度をOFFにする設定はありません。通常版では速度欄をタップして速度を変更することもできません。

### 3.2 方位磁針・方位数値

赤白の磁針は、地図上の北の向きを示します。赤側が北です。ノースアップでは北が上、ヘディングアップでは地図の回転に合わせて針が回ります。自車の進行方向を示す矢印とは役割が違います。

磁針は表示専用です。タップで地図の向きは変わりません。向きの切替には操作バーを使います。

**OS差：** Androidの縦HUD中央はカメラ穴を避ける空欄で、その右側に磁針を置きます。iOSの縦HUDは左に速度、中央に磁針、右に方位の数字を表示します。iOSの`90°`などは自車のナビゲーション方位で、北0°・東90°・南180°・西270°です。取得できないときは`---°`と表示します。横画面では両OSとも速度と磁針を同じ最上段にまとめます。

### 3.3 現在時刻と経過時間

| 項目 | 読み方 |
| --- | --- |
| 現在時刻 | 端末の現在時刻。案内や記録の開始前でも表示する |
| 経過時間 | 案内開始からの時間を優先。案内をしておらず記録中なら、記録開始からの時間 |
| `--:--:--` | 案内も記録も開始されておらず、経過時間を計測していない |
| 色が変わり、ゆっくり点滅する経過時間 | 一時停止中。経過時間の積算を止めている |

縦画面では経過時間を`01:23:45`のように時・分・秒で表示します。Androidでは時間の前のアイコンも案内／記録の状態を示します。横画面では`08:28 (8.5h)`のように現在時刻の右へ経過時間を小さく表示します。括弧内は時間単位で小数1桁へ丸めた値です。開始前は括弧内を表示しません。

### 3.4 距離進捗バー（青）

GPX案内中の`→ 27.9/37.2`は、**ルート上の現在の進捗27.9km／ルート全長37.2km**を表します。バーの青い部分が進捗、暗い部分がその先の区間です。

分子はGPX上の位置から求めた距離です。寄り道で実際に走った距離をすべて足した値ではありません。実走距離は走行ログで確認します。待機中やフリー走行記録だけの場合は、GPXの進捗バーを表示しません。

タップすると、GPX案内中は「ルート」、目的地ナビ中は「ナビ」を開きます。

目的地ナビでは、分子はナビ開始後の実走距離、分母はその実走距離と現在の経路残距離を合わせた値です。再検索で分母が変わることがあります。縦画面では`→ 0.5/33.6 (18:32)`のように到着予定時刻を併記し、横画面では予定時刻を別の旗アイコン付き行に表示します。ETAは到着予定時刻で、未取得は`--:--`、更新が保留されている場合は薄く表示します。

### 3.5 標高進捗バー（アンバー／黄橙色）

「表示 → 標高進捗表示」をONにすると、標高を計算できるGPXの案内中に表示します。iOSの項目名は「標高進捗」です。

`↑ 1,240/2,531`は、**ルート上でここまでに予定されている累積上昇量1,240m／ルート全体の予定獲得標高2,531m**です。現在地の海抜高度ではありません。下りで分子が減る表示でもありません。

数値はGPXの標高を平滑化して計算したものです。寄り道やGPS実測から得られた実走獲得標高は、終了画面や走行ログの別の値になります。GPXの標高が欠損して計算できない場合や、上昇量がない場合などは表示しません。目的地ナビの道路経路にはこのGPX標高進捗を使いません。

### 3.6 次のターンを示すコマ図パネル

白い半透明背景・青い枠のパネルです。次の案内を1件だけ表示します。

| 部分 | 意味 |
| --- | --- |
| 左の累積距離（縦画面） | そのターン／ゴールがGPXの始点から何kmの位置にあるか |
| 中央の残距離 | 現在の進捗から、そのターン／ゴールまで何km・何mか |
| 右の矢印 | 曲がる方向。左・右などの進路を簡潔に示す |
| チェッカーフラッグ | 次の表示対象がルートのゴール |

たとえば`12.4 | 500m | 右矢印`は「ルート始点から約12.4kmの地点で、現在の進捗から約500m先に右ターンがある」という意味です。残距離は1km未満でm表示になります。横画面では累積距離を省き、残距離と方向の2項目にします。

表示範囲は「表示 → ターンガイド表示」でOFF／2km以内／常時を選びます。音声のON／OFFは「音声案内」の別設定です。パネルを表示していても、音声をOFFにできます。

GPXの道筋と地図画像から候補を判断する補助案内のため、すべての交差点を案内するとは限りません。案内不要と判断された候補は除かれ、未判定の候補は従来の案内を使います。ルート逸脱中・一時停止中などはターン案内を保留します。

ターンへ接近すると地図が自動拡大し、通過後に元の縮尺へ戻ります。途中で自分でズームした場合は、その操作を優先します。

**表示OFF時のOS差：** Androidでは黄色いターン矢印も非表示になります。現行iOSではパネルのOFFと地図上のターン矢印が分かれており、パネルをOFFにしても近くのターン矢印が表示される場合があります。

### 3.7 横画面の旗アイコン付き詳細行

GPX案内では、条件に応じて残り距離を`9.3`のようにkm単位で表示します。目的地ナビでは`18:32`のように到着予定時刻を表示します。距離進捗バーや標高表示、登坂フォーカスの有無によって、この補助行を省略する場合があります。

### 3.8 地図取得の進捗

オフライン地図の取得中は、枚数や進捗をHUDに表示します。走行距離の進捗とは別の表示です。タップして取得状況を確認し、必要なら準備画面で中止します。取得の完了を待たずに案内できますが、未取得地域の圏外表示はできない場合があります。

### 3.9 登坂フォーカス（Androidのみ）

「表示 → 登坂フォーカス表示」をONにすると、GPXから検出したまとまった登りの約1km手前から、坂の断面と登頂までの情報を表示します。iOS版には、この画面と設定はまだありません。

| 要素 | 意味 |
| --- | --- |
| 坂の断面図 | GPXの標高に基づく、この登り周辺の形。横方向はルート距離、縦方向は標高 |
| 黄橙色の線 | 上り区間 |
| 青い線 | 下り区間。登坂区間内の一時的な下りも表示する |
| 白い縦線と位置の印 | 現在のルート進捗に対応する位置 |
| `登りまで`と`→ 850m` | 登坂区間の始点までの距離 |
| 登坂中の`→ 4.1km` | 登頂までの残りルート距離 |
| 登坂中の`↑ 218m` | 登頂までに予定される残り上昇量 |
| `登頂！`と`↑ 280m` | 登坂区間を通過したことと、その登り全体の予定獲得標高 |

GPS高度から現在の斜度を測る画面ではありません。登坂カテゴリやランクの表示もありません。標高を計算できないルート・目的地ナビでは表示せず、逸脱中は最後のオンルート進捗で停止します。

縦画面では地図の下部、横画面ではHUD下部へ表示します。横画面では次のターン／ゴールが300m以内になるとターンパネルを優先し、通過後に登坂表示へ戻ります。登坂フォーカスと全体の音声案内がONなら、登坂開始・登頂を一度ずつ音声で知らせます。

## 4. 地図上の線・矢印・マーカー

### 4.1 線の凡例

| 色・形 | これは何か | どう使うか／注意 |
| --- | --- | --- |
| 太い青線 | 読み込んだGPXルート | 予定されている道筋を確認する。読み込んだだけの待機状態でも表示する |
| 青線を覆う太い灰色線 | 走行済みと判定されたルート区間 | ルートのどこを通ったかを確認する。実際のGPS軌跡とは別に保持する |
| 自車から続く灰色の軌跡 | 実際に走ったオンルート／フリー走行の軌跡 | 実走経路を確認する。Androidでは点線、現行iOSでは青線より細い実線 |
| 赤い軌跡（破線） | GPXルートの外を走った軌跡 | どこでルートを離れ、どのように走ったかを確認する。これ自体が復帰経路を案内する線ではない |
| 現在地からルートへ向かう緑の点線 | ルート復帰の方向ガイド | 「ルートはあちら」という直線の目安。道路を検索した経路ではなく、通行できる道とは限らない |
| 緑の道路経路（Android）／橙色の道路経路（iOS） | 目的地ナビの検索結果 | 道路に沿ったナビに使う。GPXの青線とは異なる |
| 細い半透明のGPX線（Androidの目的地ナビ中） | 元のGPXの参照表示 | 道路ナビへの切替後も、元ルートとの位置関係を確認する |
| 紫の同心円・破線 | 距離リング | 自車を中心とする100m・500m・1kmの直線距離の目安。「表示」でON／太さを設定する |
| ティール（青緑）の実線 | 保存済み走行ログのルート案内区間 | 過去の実走を閲覧している表示。現在の案内ルートを変更しない |
| 青灰色の破線 | 保存済み走行ログのフリー走行区間 | GPX案内なしで記録した区間を示す |
| ティールの破線 | 区間情報を持たない旧形式の保存ログ | 全体を旧ログとして表示する |

灰色の「走行済みルート」と「実走軌跡」は重なって見えることがあります。ルート上を2周する場合など、すでに一度通った部分は灰色のままです。また、地図上の直近軌跡の表示と、終了時に保存する走行ログは同じ表示範囲とは限りません。保存するには、走行記録を明示的に開始してください。

目的地ナビの通信断・保留時にAndroidで目的地への点線が表示されても、その直線は道路経路ではありません。

通常の復帰ガイドは近いルート位置を指し、寄り道モードでは保持した逸脱地点を目標にする場合があります。緑点線と、明示的に検索した復帰用の道路経路を区別してください。

### 4.2 矢印と端点

| 表示 | 意味・操作 |
| --- | --- |
| 自車マーカー | 現在地と進行方向。追従OFFでも更新される |
| 白い1山の矢印（シェブロン） | GPXをたどる方向。ルートの反転で向きも変わる |
| 黄色い2山の矢印 | 次のターン地点。GPX案内では約300m以内になった次の1件だけに表示する |
| スタートの旗／端点 | 現在選んでいる方向でのルート始点 |
| チェッカーフラッグのゴール | 現在選んでいる方向でのルート終点 |
| 目的地のマーカー | 道路ナビの目的地。地図中央の照準とは別の印 |

**自車マーカーのOS差：** Androidは通常、緑の矢印を表示し、方位がない場合は丸い印になります。外部速度を使ってGPX上の位置を推定している間は黄色へ変わります。iOSは現行実装で赤い矢印、方位がない場合は緑の丸い印を表示し、Androidと同じ推定中の黄色切替はありません。iOSの赤い自車矢印だけでルート逸脱を意味するわけではありません。

GPSが弱い場所では、外部速度センサーと直前の正常なルート位置を使って進捗を推定する場合があります。これはルート上を進んだと仮定した位置で、実測の座標ではありません。推定した架空の座標を走行ログのGPS軌跡へ追加することはありません。

白い矢印はルートの方向、黄色い2山は曲がる地点、自車矢印は現在地です。形と置かれている場所を合わせて見分けてください。通常版では、画像判定で除外した候補を示す赤いターン矢印を地図に並べる表示はありません。

### 4.3 グループの仲間のマーカー

グループ参加中は、仲間を暖色の丸いバッジと小さい方位三角で表示します。丸の中の1〜2文字（数字の名前は最大3桁）は自動で割り当てられる短縮名です。短縮名が取得できない場合は番号を表示します。自分は通常の自車マーカーを使います。

仲間のバッジをタップすると、正式な表示名や位置の詳細を確認できます。最終測位時刻・何秒前か・精度・推測位置／模擬走行の表示も確認してください。古い位置は薄くなり、30秒以内・2分以内・10分以内で表示を変え、10分を超えた位置などは地図から隠します。一時停止中の仲間は地図表示から外れるため、参加状態は「メンバー一覧」で確認します。

全員の位置をまとめて見たい場合は「グループライド → メンバー一覧 → 全員を地図に表示」を使います。この操作では現在地追従が解除されるので、自車へ戻るには追従をONにしてください。

走行記録は開始した時点からのデータを保存します。案内を先に開始していても、記録開始前の軌跡をさかのぼってログへ入れることはありません。

## 6. 地図メニュー

### 6.1 地図ソース

| 選択肢 | Android | iOS |
| --- | --- | --- |
| 自動 | 通信可能時はGoogle Maps、通信不能時などは保存済み地理院標準へ切り替える | 通信可能時はApple Maps、通信不能時は保存済み地理院標準へ切り替える |
| Google／Apple | AndroidはGoogleを優先し、利用できないときは地理院標準へ退避 | iOSはAppleの標準地図を選ぶ |

ボタンを押すと表示地図が切り替わります。ルート・記録・地図の向きは保持します。「自動」は通信復帰後に安定を確認して標準地図へ戻るため、通信が戻ってもすぐには切り替わらない場合があります。

保存できる地図は地理院標準です。Google／Apple／OSMを選んだから、その地図全体をこのアプリがオフライン保存するという意味ではありません。圏外に備えるには、ルート詳細からオフライン準備を行ってください。

### 6.2 オフライン地図をすべて削除

全ルートで共用する保存済み地図を削除します。確認画面の内容を読んで確定してください。GPX原本や走行ログの削除とは別の操作です。

地図取得・準備ジョブがある間は削除できません。必要なら先に準備を中止します。削除後は、圏外表示や画像によるターン判定のために地図の再取得が必要になる場合があります。

### 6.3 移動モード／移動方法

「自動車」または「自転車」を選びます。Androidの表記は「移動モード」、iOSは「移動方法」です。目的地までの道路経路検索に使う指定で、GPXの道筋や色を変更する設定ではありません。

### 6.4 目的地ナビ / Routes API（Androidのみ）

| 項目 | 意味・操作 |
| --- | --- |
| APIキー：登録済み／未登録 | 利用者のRoutes APIキーを保存しているかを示す |
| Routes APIキー入力 | 自分で用意したキーを入力する。内容は隠して表示する |
| 保存 | 入力したキーを端末に保存する |
| 削除 | 保存済みのキーを削除する。以後、キーが必要な目的地ナビを使えなくなる |
| パッケージ | このアプリのパッケージ識別子。キーのAndroidアプリ制限を設定する際に使う |
| SHA-1 | 端末に入っているアプリの署名識別値。キーの制限を設定する際に使う |

利用者自身のRoutes APIキーが必要なのは、Androidの道路経路検索です。**GPX案内やGoogle地図の通常表示に、このキーは不要です。** キーは端末上で暗号化して保存します。

Androidの目的地ナビにはインターネット接続・現在地・Google地図が利用できる状態が必要です。iOSはAppleのMapKitで経路を検索するため、このAPIキー入力・パッケージ・SHA-1の項目はありません。経路検索結果もOSによって異なります。

## 7. ルートメニュー・ライブラリ・オフライン準備

### 7.1 ルートライブラリ一覧

「ルート」を開くと、端末に保存したGPX原本の一覧を表示します。ルート名と距離を見て選ぶと、地図プレビュー付きの詳細を開きます。案内中のルートには案内中／一時停止中などの表示が付きます。

| 項目 | 意味・操作 |
| --- | --- |
| ルート読込 | OSのファイル選択画面からGPXを選ぶ |
| ルート受信 | GPX Compassの共有QR／リンクを受け取る。利用できる版の条件は後述 |
| 保存済みルートの行 | 詳細を開く。閲覧だけでは現在の案内を切り替えない |
| 原本を利用できません／原本欠損 | 保存ファイルを読めない状態。同じ原本を読み込み直すか、不要なら削除する |
| 保存索引のエラーと再試行 | 一覧の読込に失敗した状態。「再試行」で再読込する |

ファイル・QR・グループから同じGPX原本を取り込んだ場合は、同じ原本を1つの項目にまとめます。保存したルートは次回起動時も使えます。端末間でライブラリを自動同期する機能ではありません。

GPXはファイル選択のほか、対応するURLの共有からも取り込めます。Ride with GPSのルート／トリップリンクにも対応します。共有元にログインが必要なファイルや、非公開リンクは読み込めない場合があります。

**iOSの他アプリからの共有：** 共有シートでGPX Compassを選んだ後、本体アプリを開くと共有内容を取り込みます。共有画面を閉じただけで案内が開始されるわけではありません。

### 7.2 ルート詳細の全項目

| 項目 | 意味・操作 |
| --- | --- |
| 地図プレビュー | 選択ルートの全体・スタート・ゴールを確認する。Androidは原則Google、iOSはAppleの地図を使い、走行地図の選択と異なる場合がある |
| ルート名と鉛筆 | 鉛筆を押して表示名を変更する。空欄は不可、80文字以内。GPX原本の内容は書き換えない |
| 距離 | GPX上のルート全長 |
| 獲得標高 | GPXから計算した予定上昇量。「計算中」は解析中、`--`は計算不能 |
| 保存済み地図の枚数／オフライン準備状態 | このルートに必要な地図の保存状況。枚数と準備状態を確認する |
| スタート地点までナビ | 現在選んだ方向の始点まで道路経路を検索する。GPXをたどる案内とは別の機能 |
| ゴール地点までナビ | 現在選んだ方向の終点まで道路経路を検索する。GPXの全区間を通ることは保証しない |
| オフライン準備開始／オフライン準備状況 | ルート周辺の地図取得・画像判定を開始、または状況を確認する |
| ルート反転 | GPXを逆方向にたどる設定へ変更する。スタート／ゴールと案内方向が入れ替わる。原本はそのまま保持する |
| このルートを共有 | QR／リンクによる単独ルート共有を開く。利用できる版の条件は後述 |
| ルート走行開始 | 選択したルートの案内を開始する。別ルートを案内中なら切替を確定する。走行記録と一時停止状態は保持する |
| 地図に戻る | 詳細を閉じる。押すだけでは案内を開始しない |
| ライブラリから削除 | この端末のGPX原本を削除する。iOSは「ルート原本を削除」。確認して実行する。使用中の原本は先に案内を終了する |

走行中のルート詳細では、案内終了・寄り道・復帰ナビの操作も表示します。Androidでは走行中ルートの主ボタンが「地図に戻る」になり、スタート／ゴールへのナビを省きます。iOSでは詳細内に「ルート走行開始」や端点へのナビも表示する構成です。押す前に、現在の案内を続けたいのか、改めて開始／切替したいのかを確認してください。

ルートの反転は、表示方向・進捗・案内候補に影響します。走行前に設定してください。詳細で別ルートを閲覧したことや、共有ルートを受信したことだけでは、案内中のルートは変わりません。

「ルート案内を停止」は案内だけを終えます。保存したライブラリ原本は残ります。旧画面などに「ルートクリア」がある場合は、地図に保持しているルートを外す操作です。ライブラリ原本の削除、地図の削除、走行ログの削除はそれぞれ別の操作です。

### 7.3 寄り道モードと逸脱地点へのナビ

給油・休憩などで意図的にGPXを離れるときに使います。

| 項目／状態 | 意味・操作 |
| --- | --- |
| 寄り道モード | ONにすると、逸脱開始と繰り返しの逸脱音声を抑える。iOSの詳細では「迂回モード ON／OFF」と表示する |
| 逸脱待ち | まだルート上。離れるまで、最後の正常なルート上位置を更新している |
| 寄り道中 | 逸脱を確定し、その前のルート上位置を戻る目標として保持している |
| 逸脱地点までナビ | 保持した地点まで道路経路を検索する。iOSの詳細では「離脱地点へ戻る」。AndroidはRoutes APIキー・Google地図・通信が必要 |
| 逸脱地点をまだ確定できません | 戻る目標を決められていないため、道路ナビを開始できない |
| 逸脱地点ナビを中止／復帰ナビを中止 | 道路での復帰案内を止める。寄り道モード自体は継続する |
| 寄り道モードOFF | 寄り道モードと復帰ナビを終了する |

寄り道中も走行記録は続きます。休憩時間や休憩中の移動を記録したくない場合は、メインメニューの「一時停止」を使ってください。

ルート復帰が確定すると寄り道モードと復帰ナビを自動終了し、通常のGPX案内へ戻ります。戻る目標は、寄り道中に近くを通った別区間へ勝手に変更しません。道路経路を取れない場合は通信を確認し、地図の緑点線を方向の目安として確認します。

### 7.4 オフライン準備の各項目

オフライン準備は、圏外で使う地理院標準地図と、画像によるターン判定の準備です。表示地図をGoogle／Apple／OSMにしていても、準備には地理院標準を使います。

| 項目 | 意味・操作 |
| --- | --- |
| 対象地図・範囲 | 地理院標準のルート周辺約500m。原画は保存Z17を使う |
| 総枚数・概算容量 | 必要な地図枚数と保存量の目安。長いルートほど増える |
| 保存枚数／総枚数・プログレスバー | 地図の取得進捗。ルート距離の進捗とは別 |
| オフライン準備開始／開始／再試行 | 準備を開始する。中断後は保存済みデータを使い、不足分を取得する |
| 待機中／準備中／取得中／画像判定中 | 実行段階。地図取得完了後も画像判定が続く場合がある |
| 中止／準備を中止 | 対象の準備を中止する。取得済み地図は残る |
| 保存完了／失敗／中止 | 結果。失敗時は通信と空き容量を確認して再試行する |
| 地理院タイル利用案内 | 使用する地図の出典・利用案内を開く |

詳細を開く・GPXを受信するだけでは地図取得を始めません。「オフライン準備開始」または確認したルート走行開始で準備します。事前に通信が安定した場所で準備することをおすすめします。

詳細やメニューを閉じても、明示的に開始した準備は中止しません。背景や画面消灯中の取得継続はOSの制約があるため、準備完了まではアプリを前面にして結果を確認してください。案内は準備完了を待たず開始できます。

広域表示では、保存したルート周辺以外が空白／灰色になることがあります。全国の広域地図をまとめて保存する機能ではありません。地図を削除する操作は「地図 → オフライン地図をすべて削除」にあります。

### 7.5 QR・リンクによる単独ルート共有

グループライドへ参加せず、GPX原本を渡す機能です。送信・受信には通信が必要です。

**利用条件：** 現在のiOS Release構成では、この単独QR共有の接続設定が空で、「ルート受信」「このルートを共有」が無効になります。グループでのGPX配布とは別です。以下は共有サービスが設定された版での操作です。Androidもサービスが設定されている版で利用します。

| 送る側の項目 | 意味・操作 |
| --- | --- |
| GPX名・距離・容量・注意文 | 共有する対象を確認する。GPX原本の時刻・コメントなども渡る |
| QRを作成／アップロード再試行 | 原本をアップロードし、共有QRを発行する。通信失敗時は同じ要求で再試行する |
| QRと有効期限 | 発行完了したリンク。公開完了から24時間有効 |
| リンクを共有／コピー | QRを撮影できない相手へ、OSの共有機能などでリンクを渡す |
| 共有を停止 | 新しい受信を停止する。すでに相手が保存したコピーは削除できない |

| 受け取る側の項目 | 意味・操作 |
| --- | --- |
| QRで受け取る | カメラでGPX Compassの共有QRを読む |
| 共有リンクを貼り付け | 受け取ったリンクを貼り、受信を確定する |
| 受け取る／再試行 | GPXを検証して保存する。期限切れは送信者に新しいQRの発行を依頼する |
| ルートを開く | 保存した原本の詳細を開く。走行開始は別に確定する |
| 削除 | 端末に保存した原本を削除する。送信者の共有停止とは別 |

カメラが使えない場合は標準カメラでリンクを開くか、リンクを貼り付けます。他アプリ独自のQRがすべて読めるわけではありません。転送対象は10MiB・100,000点までです。リンク期限後も受信済みの端末コピーは利用できます。

受信によって案内・記録・位置共有が自動開始されることはありません。案内中でも現在の案内は保持します。原本削除と共有停止も別操作です。

## 8. ナビメニュー

GPXから離れた地点、宿泊先、スタート地点などへの道路ナビに使います。AndroidはGoogle Routes API、iOSはApple MapKitの経路を使うため、道路の選択や案内文が異なることがあります。

### 8.1 全項目

| 項目 | 意味・操作 |
| --- | --- |
| 地図から選ぶ | 地図中央へ照準を出す。地図を動かして目的地を合わせる |
| ここへナビ | 照準の地点を確定して道路経路を検索する |
| キャンセル | 地点選択をやめて通常地図へ戻る |
| お気に入り | 保存した目的地の一覧。地点名のボタンでナビを開始する |
| 最近の目的地 | 経路取得に成功した目的地の履歴。新しい順に最大20件 |
| 星／お気に入りへ追加 | 履歴の地点をお気に入りへ登録する。登録済みなら星で示す |
| 鉛筆／名称を編集 | お気に入りの名前を編集し「保存」で確定する。履歴の名前編集はない |
| ごみ箱／削除 | お気に入りまたは履歴のその項目を削除する。現在進行中のナビは停止しない |
| ナビを中止 | 目的地ナビを停止する。走行記録は継続する |
| 経路を再検索 | 失敗・保留状態など、表示される場合に再試行する。iOSのナビページに明示的な入口がある |
| 目的地名・残距離・ETA・状態文 | 現在の道路ナビの対象と、検索中／案内中／保留／失敗などの状態 |

お気に入りの名称変更は、入力後に保存して確定します。地点座標は変わりません。最近の目的地では約25m以内の地点を同一地点としてまとめます。履歴には道路経路そのものを保存しません。

### 8.2 地図アプリから目的地を受け取る

AndroidはGoogleマップの地点共有、iOSはApple Mapsの地点共有が主な入口です。共有先でGPX Compassを選び、iOSの場合は本体アプリを開いて受信します。対応する座標または住所を読み取れた場合に経路検索します。アプリ内の施設名検索・住所検索欄はありません。

別の案内中に新しい目的地を受け取っても、経路取得に成功するまでは現在の案内を維持します。検索成功時に目的地ナビへ切り替えます。GPX案内から切り替えると、そのGPX案内区間を終了します。

### 8.3 道路ナビ中の動作

取得した経路から外れると、通信できる場合は再検索します。通信断では新しい経路を取得できません。元の情報が残っていても、最新の道路状況を取得できているとは限らないため、状態表示を確認してください。

目的地ナビを開始するだけでは走行記録は始まりません。記録中ならそのまま継続します。スタート地点へのナビが終わったら、GPXをたどるには改めて「ルート走行開始」を押してください。任意目的地への到着・中止後も、待機している元GPXの案内を自動再開しません。寄り道の復帰ナビは[別の動作](#route-menu)です。

## 9. 走行ログメニュー

### 9.1 一覧

保存した走行を新しい順に表示します。各行の走行名・日時・距離・実走獲得標高を見て選びます。

- `↑0 m`：標高を計算できた平坦な走行です。
- `↑計算中`：保存した軌跡の標高を解析しています。
- `↑--`：標高不足などで計算できません。GPX予定ルートの上昇量で埋めることはありません。

日時は端末のタイムゾーンで表示します。標高を持たない古いログでは、獲得標高を表示できないことがあります。

### 9.2 詳細の全項目

| 項目 | 意味・操作 |
| --- | --- |
| 走行名と編集 | 走行名を変更する。空欄不可、80文字以内。案内に使った元ルート名の内訳は変更しない |
| 小さい地図プレビュー | 保存した軌跡全体。タップすると全画面で見る |
| GPX共有 | 保存した実走GPXをOSの共有シートへ渡す。外部アプリや保存先を選ぶ |
| 削除 | 保存ログを削除する。確認して確定する |
| 距離 | 記録中に積算した実走距離 |
| 獲得標高 | 記録したGPS高度から計算した実走累積上昇量 |
| 平均速度 | 記録距離と実走時間から求めた平均速度 |
| 総時間 | 開始から終了までの経過時間。休憩を含む |
| 実走時間 | 一時停止時間を除いた記録時間 |
| 記録点数 | 保存したGPSトラック点の数 |
| 種類／ルート名一覧 | フリー走行か、どのルートを案内しながら記録したか |
| GPS／CSC／OBD2の距離内訳 | 各情報源で積算した距離の内訳。GPS点の軌跡と外部センサーによる距離は測定方法が異なる |
| ソース切替回数 | 距離積算に使う情報源が切り替わった回数 |
| 区間内訳 | 記録中に案内した各ルート区間の距離・時間など |
| 区間のGPX共有 | その案内区間に実際に記録した軌跡だけを切り出して共有する |

走行ログのGPXは実際の軌跡です。元の予定GPXを渡したいときは「ルート」の共有を使います。記録時の一時停止区間や、GPS位置を取得できなかった区間を、元の予定ルートで補って保存することはありません。

走行記録中は、保存済みログの地図・共有・編集・削除を制限します。ログ操作が押せない場合は、現在の記録を終了してから使ってください。GPX案内のみで記録していない場合の閲覧とは条件が異なります。

### 9.3 全画面地図の閉じ方

過去ログは通常地図への一時的な重ね表示として開きます。現在のルート・距離・セッションを置き換えません。拡大／縮小・向き・追従のボタンを使えます。

右上の閉じるボタンではログ詳細へ戻ります。メニューボタンでログ地図を閉じると通常地図へ戻り、通常地図のズーム・追従状態を復元します。Androidの戻る操作でも詳細へ戻れます。

### 9.4 記録終了時の保存画面

終了時は走行名を確認・編集し、距離・獲得標高・時間・距離ソース内訳などの結果を確認して「保存」を押します。標高計算中は保存を待つ場合があります。保存せず捨てる場合は、画面の「長押しで破棄」などの操作を使います。

案内だけを終了したサマリーと、走行記録全体の保存画面は別です。「走行記録は継続中」と出ている場合、まだ記録全体は終了していません。

## 11. 音声案内メニュー

| 項目 | 選択肢 | 意味・操作 |
| --- | --- | --- |
| 音声案内 | OFF／ON | 音声全体のスイッチ。OFFでは下の個別項目の操作も無効になる |
| ルート逸脱・復帰音声 | OFF／ON | GPXを外れたこと、外れた状態の継続、戻ったことを知らせる |
| ターンガイド音声 | OFF／ON | 次のターンへの接近・曲がる方向を読み上げる |
| 定時アナウンス | OFF／10分／30分／60分 | 指定間隔で現在時刻・進捗・次ターンなどの状況を読み上げる |
| チャイム | なし／1回／2回 | 読み上げ前のチャイム回数。直前案内や割り込みでは省く場合がある |
| 案内音量ブースト（Androidのみ） | OFF／＋2／＋4／最大付近 | 案内中だけメディア音量を一時的に上げる。案内終了後は元に戻す |

表示の「ターンガイドOFF」と、音声の「ターンガイド音声OFF」は別の設定です。画面だけ・音声だけを使うこともできます。

GPXのターン音声は、おおむね300m・100m・直前の3段階で知らせます。開始タイミングは速度・発話時間などで調整するため、表示距離がちょうど300m／100mの瞬間に鳴るとは限りません。途中開始や近接したターンでは早期案内を省く場合があります。目的地ナビの道路案内は、GPXとは異なる時間基準で事前・直前に知らせます。

ゴール到達、Androidの登坂開始・登頂、手動の現在状況アナウンスには独立したON／OFF項目がありません。全体の音声案内設定に従います。寄り道モードでは逸脱の繰り返し音声を抑えます。

**iOS差：** 案内音量ブーストはありません。iPhoneのシステム音量を音量ボタンなどで調整してください。Androidでも、ブースト中に自分で音量を変更した場合は、その操作を優先します。

Androidでは本体の音量上下キーで現在状況を読み上げられます。読み上げ直後などにもう一度押すと通常の音量調整に使えます。音声OFFでは通常の音量調整を優先します。iOSの本体音量キーは音量調整に使い、状況読み上げ操作へ割り当てません。

## 12. 表示メニュー・タッチロック

### 12.1 全設定項目

| 項目 | 選択肢・操作 | 意味 |
| --- | --- | --- |
| 距離リング表示 | OFF／太さ | 自車中心の100m・500m・1kmの紫色破線を表示する。太さのボタンで選び、適用するとONになる |
| ターンガイド表示 | OFF／2km以内／常時 | OFFはパネルを表示しない。2km以内は次ターン／ゴールが2km以内にあるときだけ表示。常時は距離に関係なく次の1件を表示。iOSの見出しは「ターンガイド」 |
| 標高進捗表示 | OFF／ON | GPXの予定獲得標高進捗を表示する。iOSの見出しは「標高進捗」 |
| 登坂フォーカス表示（Androidのみ） | OFF／ON | 検出した登りの断面と登頂までの距離・上昇量を表示する |
| 省電力モード | OFF／ON | 操作がないと減光し、位置・地図・保存などの更新負荷を抑える |
| 操作バー自動非表示 | OFF／ON | 案内中に10km/h以上が5秒続くと、操作バーを隠して地図を広くする |
| 走行中は通知を抑える（Androidのみ） | OFF／ON | GPXまたは目的地案内中の通知音・ポップアップを抑える |
| Androidの通知設定（条件付き） | OS設定を開く | 通知抑制の許可や例外を調整する。許可／専用ルールの再設定が必要な場合も表示する |
| 画面の向き | 端末設定／縦／横 | OSの設定に従うか、アプリの画面方向を固定する |

未設定時は、距離リング・標高進捗・登坂フォーカス・手動省電力・操作バー自動非表示・Androidの通知抑制はOFF、ターンガイドは常時、画面方向は端末設定です。以前保存した設定は維持します。

速度表示は常時ONです。HUD文字サイズ・通常の地図線幅・アクセント色は固定されており、変更用メニューはありません。距離リングの太さだけは個別に選べます。

### 12.2 距離リングの太さ

現行ソースでは、太さのボタンを押し、1〜10ptの整数をスクロールして選びます。「適用」で保存してリングをONにし、「キャンセル」では表示状態と保存値を変えません。OFFにしても前回の太さは保持します。未設定の太さは6ptです。

**配信版との差：** この整数ピッカーと未設定時6ptは、提出済み0.97.1の後の変更です。提出時点の実装は0.5〜10ptの数値入力・未設定時3ptでした。手元の版が数値入力の場合は範囲内の値を入力して適用してください。旧版で保存した小数値は、更新後も自動で整数へ書き換えません。

Androidは数値ピッカー、iOSはホイールを使います。Androidのpt表記は画面の論理幅、iOSはUIKitのptです。自車位置を取得できない場合はリングを表示しません。リングの距離は円の中心からの直線距離で、道路を走る距離とは異なります。

### 12.3 省電力モード

手動ON、またはOSのバッテリーセーバー／低電力モードがONの場合に有効になります。アプリ側がOFFでも、OS側の設定によって有効になることがあります。外部給電だけでは自動解除しません。

操作から約15秒経つと、画面を黒く覆って減光します。案内・記録自体は続きます。**最初のタッチは画面を戻すために使い、背後のボタンを押す操作にはしません。** 必要なボタンは復帰後に押してください。

ターンの100m相当の事前案内・直前案内で画面が復帰する場合があります。300m相当の早期案内や、すべての音声で復帰する設定ではありません。

Androidでは本体音量キーや対応する外部コントローラー操作でも復帰できます。本体音量キーでは、音声ONなら現在状況も読み上げます。iOSは画面タッチを使い、本体音量キーへの復帰操作の割当はありません。OSの実際の消灯・端末ロックとは違う動作です。

### 12.4 操作バー自動非表示

ONでは、GPXまたは目的地案内中に10km/h以上が5秒続くと操作バーを隠します。速度低下・停止だけでは再表示しません。画面を一度触ると、その接触を復帰専用として使い、操作バーを表示します。

表示した後は操作のたびに15秒の猶予を更新し、条件を満たすと再び隠します。メニューや確認画面の表示中は隠しません。明示的なタッチロックとは別の機能です。

### 12.5 走行中の通知抑制（Androidのみ）

初回ONでは、Androidの通知ポリシーへのアクセスを許可し、GPX Compass専用のおやすみモードを使えるようにします。画面の案内に沿ってOS設定を開いてください。

GPX／目的地案内が動作中の間に有効となり、一時停止・案内終了で戻します。記録のみの走行は対象外です。着信などの例外は「Androidの通知設定」で調整します。ナビ音声とアラームは初期設定で許可します。

権限取消や専用ルールの削除で使えなくなった場合は、再設定の表示が出ます。iOSにはこの項目がないため、必要に応じてOS側の集中モードなどを設定してください。

### 12.6 画面の向き

端末設定はOSの自動回転／回転ロックに従います。縦／横はアプリからその向きを要求し、選択を保存します。iPadの分割表示やAndroidの大画面・マルチウィンドウでは、OSの制約で固定要求が適用されない場合があります。その場合は実際のウィンドウ寸法に合わせて表示します。

### 12.7 タッチロック

雨滴や手袋による誤操作を防ぐため、地図とアプリのタッチ操作をロックできます。設定メニューのON／OFFではなく、HUDで操作します。

1. メニューや入力画面を閉じ、通常の地図画面へ戻ります。
2. **HUD先頭2段の速度・磁針・時計・経過時間の領域を約2秒長押し**します。
3. 画面中央の円形進捗が満ちるとロックします。途中で指を離す・移動する・複数指で触ると中止します。
4. 解除は、**同じHUD領域を5秒以内に10回、短く連続タップ**します。毎回指を離してください。

ロック中は操作バーを隠して地図を広げます。HUD・案内・記録は維持します。解除用のタップに応じて中央の円が進み、10回完了で解除します。領域外への接触、長押し、大きな移動、複数指、時間切れでは途中の回数をリセットします。長押しでの解除はありません。

省電力で黒くなっている場合は、最初のタッチで画面を戻してから解除操作をしてください。OSのホーム操作や端末ロックを完全に禁止する機能ではありません。

iOSのVoiceOverでは、HUDの「タッチ操作をロック」、ロック中の「タッチ操作を解除」というアクセシビリティアクションも使えます。

<a id="devices"></a>

## 13. 外部デバイスメニュー

外部デバイスなしでもGPSで利用できます。CSCやOBD2は、速度・距離の計測やGPSが弱い場所でのルート進捗推定を補助します。OSのBluetooth／付近のデバイスなどの許可を求められた場合は、使う機器に応じて許可してください。

### 13.1 共通の採用操作

「登録」は機器を覚える操作、「採用」は今回の走行で使う速度センサーを選ぶ操作です。

| 項目 | 意味・操作 |
| --- | --- |
| 登録済み | 保存している機器一覧 |
| 自動選択中／自動選択に戻す | 有効な速度データを送っている登録機器を自動で選ぶ |
| 採用／採用中 | この機器を明示的に選ぶ／選択されていることを示す。iOSではチェックのボタンを使う |
| 表示名 | 自分が識別しやすい名前へ変更する |
| ID | 機器の識別値。AndroidとiOSではBluetoothの識別方式が異なるため、別OSのIDをそのまま流用しない |
| 接続・受信・待機などの状態 | 接続しただけでなく速度データが届いているかを確認する |
| ごみ箱／削除 | 機器の登録を解除する |

採用後はその1台を使います。切断時には再接続を試み、同じ走行で別の登録機器へ勝手に乗り換えることはありません。別の車両／機器へ切り替える場合は採用操作か自動選択へ戻す操作を使います。センサーの接続状態とHUDに採用される速度の状態は同じ意味ではありません。有効な外部速度がないときはGPSなどを使います。

### 13.2 CSC スピードセンサー

自転車用のBLE車輪回転センサーです。ケイデンスだけを送る機器では、車輪速度を得られません。

| 項目 | 意味・操作 |
| --- | --- |
| 新規登録／スキャン開始 | センサーを起こし、周囲の対応機器を探す。iOSは「新規登録スキャン」 |
| 候補・名前・ID・RSSI | 見つかった機器。RSSIは電波強度の参考値 |
| タップで登録 | 自分の機器を選んで登録する |
| スキャン停止／停止 | 探索を終了する |
| タイヤ周長 mm | 車輪1回転で進む距離をmmで指定する。外径・半径ではない |
| GPSによる周長自動補正／GPS自動校正 | 初期ON。高精度GPSと安定した走行から徐々に周長を補正する。OFFでは手動値を固定する |
| 校正状態・サンプル数・距離・推定周長 | 校正が進んでいるかを確認する。待機中は条件のよいGPS／走行を待つ |
| iOSの−／＋ | 周長の微調整 |
| iOSの一時停止／再生ボタン | そのセンサーの有効／無効を切り替える |

AndroidではID・表示名・タイヤ周長を入力して登録する入口もあります。通常はスキャンを使う方が機器を確認しやすくなります。

周長が大きすぎると速度・距離を大きく算出します。実際のタイヤ周長を設定してください。校正は低速・停止中や精度の悪いGPSから無理に更新する機能ではありません。校正が始まらないだけで接続失敗とは限りません。

### 13.3 ELM327 OBD2 スキャナ

車両の車速データを取得するアダプターです。アダプターだけでなく、車両側が車速PID（010D）に対応している必要があります。

| 項目 | 意味・操作 |
| --- | --- |
| 候補をスキャン | 周辺の機器を探す |
| 確認／候補を確認 | 候補へ接続し、ELM327や車速取得への対応を調べる |
| 確認中／判定結果 | 調査中、対応候補、対応しない機器などの結果 |
| 登録 | 確認した機器を保存する |
| 停止 | スキャン／確認処理を止める |
| 通信：BLE／Classic（Androidのみ） | 機器の通信方式。AndroidはClassic Bluetoothにも対応する |
| ID・表示名の手動登録（Android） | 識別値と通信方式が分かっている機器を登録する |
| 速度補正 | 取得した速度へ掛ける係数。`1.000`は補正なし、`1.020`は約2%増加 |
| iOSの−／＋ | 速度補正係数の微調整 |
| iOSの一時停止／再生ボタン | そのスキャナの有効／無効を切り替える |
| 採用／自動選択 | 使用するスキャナを指定するか、共通の自動選択へ戻す |
| 診断状態 | ELM327情報、電圧、車両プロトコル、PID対応、車速、コマンド／応答などを確認する |

**iOSはBLEのみ対応**です。Classic Bluetooth SPPのELM327は使えません。BLEと記載された機器でも、車速を取得できるかは候補の確認結果を見てください。接続を確認する際は車両の電源状態も確認します。

診断の電圧は車両側の情報で、スマートフォンのバッテリー残量ではありません。診断データを扱う画面は、一般的な車両整備診断の全機能を提供するものではありません。

### 13.4 コントローラー（Androidのみ）

Bluetoothリモコンなどのキー入力をアプリの操作へ割り当てます。iOSにはHID・ゲーム・メディアコントローラーの操作画面と割当機能はありません。

1. Androidの設定で対応する入力機器を接続します。
2. 「外部デバイス → コントローラー」を開き、その機器のボタンを押します。
3. 「最後のキー入力」のデバイス名などを確認し、「この入力デバイスを登録」を押します。
4. 登録した機器のボタンを押し、対応させたい操作を選んで「最後のキー」を割り当てます。
5. 必要なボタンごとに繰り返します。

| 項目 | 意味・操作 |
| --- | --- |
| 最後のキー入力 | 最後に受け取ったキーコード、押下／解放、repeat、スキャンコード、デバイス名など。割当対象を確認する |
| この入力デバイスを登録 | 最後に押したキーの機器を登録する |
| 表示名 | 登録機器の呼び名を変更する |
| 採用／採用中 | 今回使用する登録コントローラーを選ぶ |
| 有効／無効 | 機器からの操作を有効化／無効化する |
| 最後のキーを割り当て／操作ボタン | 直前に押した、そのコントローラーのキーを選んだ操作へ対応させる |
| 割り当て一覧と削除 | キーと操作の対応を確認し、不要な割当を消す |
| 機器のごみ箱 | コントローラー登録を削除する |

割り当てられる操作は次のとおりです。

| 操作 | 動作 |
| --- | --- |
| 地図拡大／地図縮小 | ＋／−と同じズーム操作 |
| 地図向き切替 | ノースアップ／ヘディングアップ切替 |
| 現在状況アナウンス | 音声ONのとき、現在時刻・進捗・次ターンなどを読み上げる |
| スクリーンショット | 画面保存の操作。Google地図を含むアプリ内診断画像には保存制限がある |
| 音声案内 ON/OFF | 全体の音声設定を切り替える |
| この案内は不要 | 直近に実際に発声したターンに、不要だったという評価を保存する。その場で案内ルールやモデルを学習し直す操作ではない |

「この案内は不要」の対象は、直近にターン音声が発声された候補です。次候補の最初の音声が発声されると対象を更新します。対応する音声がない場合、意図した候補へ評価できないことがあります。

<a id="troubleshooting"></a>

## 16. 表示や操作で困ったとき

| 症状 | 確認すること |
| --- | --- |
| GPXの青線は出るが進捗や案内が始まらない | 読込／待機だけでは開始しない。ルート詳細で「ルート走行開始」を押す |
| 走ったのにログがない | 案内だけでは記録しない。「記録開始／走行記録も開始」を押し、終了時に保存する |
| 青線が灰色になった | その区間を走行済みと判定した表示。GPXが消えたわけではない |
| 赤い線が出た | オフルート軌跡。青線との位置関係と緑の復帰ガイドを確認する |
| iOSの自車矢印が赤い | 通常の自車色。これだけで逸脱とは判断しない |
| 緑点線が道のない場所を横切る | 復帰方向の直線ガイド。道路経路ではない。必要なら逸脱地点への道路ナビを明示的に使う |
| 地図が指で動かした場所から戻る | 現在地追従ONでは約5秒後に戻る。見続けたい場合は追従OFF |
| 地図の一部が灰色／空白 | 圏外、取得不足、保存範囲外、広域表示など。「地図」とオフライン準備状況を確認する |
| 画面が黒くなる | 省電力設定またはOSの低電力設定。一度触って復帰する |
| 操作バーがない | 自動非表示なら一度タッチ。タッチロックならHUDを5秒以内に10回タップして解除する |
| ターンが表示されない | 表示OFF、2km以内条件、逸脱、一時停止、不要候補の除外などを確認する |
| 標高バー／登坂がない | 標高表示設定、GPXの標高欠損、目的地ナビ中などを確認。登坂フォーカスはAndroidのみ |
| 音が出ない | 全体と個別の音声ON、端末音量、Bluetooth音声の接続先、一時停止状態を確認する |
| Androidの道路ナビが始まらない | Routes APIキー、通信、現在地、Google地図の利用状態を確認する |
| iOSのルート受信／共有が押せない | 現行Releaseの単独QR共有は未設定。ファイル読込やグループGPX配布と区別する |
| 仲間が地図にいない | 相手の共有停止、古い測位、位置未取得、通信状態を一覧で確認する |
| 案内を終了したのに共有が続く | グループ位置共有は独立。「グループライド」で一時停止／退出する |
| センサーを登録したが速度が変わらない | 採用・接続・実データ受信、CSCの車輪回転／周長、OBD2の車速対応を確認する |
| 画面を消す／他アプリへ移ると記録が不安定 | OSの位置権限・背景実行・省電力制限を確認する。iOSは背景位置の許可、Androidは走行通知や位置許可も確認する |

問い合わせ時はOS、端末名、アプリのバージョン／ビルド、使用地図、案内・記録・位置共有のどれを使っていたかを添えると、状況を特定しやすくなります。

| 表示／操作 | 意味 |

| 推定状態・GPS精度など | 実測／推定の判別、位置情報の品質確認 |
| 自動走行中の速度欄タップ | 10／20／40／60／80km/hなどの候補、または5〜999km/hの任意速度を選ぶ |
| 自動走行中の距離進捗操作 | 模擬位置をルートの任意の進捗へ移す |

模擬走行は実走ログへ架空のGPS軌跡を追加する操作ではありません。ただしグループへ模擬位置が共有される場合があるため、共有状態も確認してください。停止すると実GPSの入力へ戻ります。

### C. 走行ログ → ターンガイド履歴

実際の案内候補・判定・音声・評価を検証するための履歴です。通常版の保存走行ログ一覧とは別です。

| 項目 | 意味・操作 |
| --- | --- |
| セッション一覧と件数・抑制件数 | 対象のルート案内を選ぶ |
| モード・モデル・処理状態 | どの条件で判定したかを確認する |
| 候補一覧／前後の候補切替 | 調べたいターン候補へ移る |
| 地図 | 候補地点と、記録がある場合のルート形状を確認する |
| 確率・閾値・理由・音声履歴 | 判定と案内の記録を確認する |
| 評価 | 必要／不要などの評価を保存・変更する |
| 見落とし地点などの記録 | 表示される版では、案内されなかった地点を記録する |
| 共有 | 保存データやJSONL／診断エクスポートをOSの共有機能へ渡す |
| 削除 | 対象の診断履歴を確認して削除する |

評価の保存は、製品の判定をその場で変更する設定ではありません。保存データにルート点がない旧履歴では、地図は候補点中心の表示になります。iOSにはApple Mapsで候補地点を開く導線もあります。
