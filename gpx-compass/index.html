GPX Compass クイックスタートガイド

GPX Compassは、あらかじめ用意したGPXルートを辿るためのナビゲーション補助アプリです。もう一つの使い方として、Google Routes APIで任意の目的地への経路を検索し、案内する機能も備えています。

Android版 0.80.2 の日本語画面を基準に説明しています。更新日: 2026年9月25日

まずは「ルート」と「ナビ」の違い

選ぶ基準は、「走る道が決まっているか」「行き先だけが決まっているか」です。

BEFORE YOU RIDE

初回の準備

  1. 端末の位置情報をONにし、アプリから求められたら位置情報の利用を許可します。正確な位置情報を有効にしてください。
  2. 通知の許可を求められたら、案内・記録の動作状態を確認できるよう許可してください。
  3. 屋外などGPSを受信しやすい場所で、地図上に現在地が表示されることを確かめます。
  4. 音声を使う場合は、メニューの「音声案内」で設定し、端末の音量とBluetooth機器への出力を確認します。

以下の手順は、地図画面のメニューボタンから始めます。Bluetoothセンサーなどの外部機器は、使い始めるための必須条件ではありません。

設定や目的地選択は、安全な場所に停車して行ってください。案内は補助情報です。実際の標識、通行規制、路面状況を優先してください。

01 · 「ルート」メニュー

GPXルートを辿る

あらかじめルート作成サービスなどからGPXファイルを入手し、端末から選べる場所に保存しておきます。

  1. 「ルート」→「GPX読込」でファイルを選ぶ

    読み込み後、ルート全体のプレビューが表示されます。コースと進む向きを確認してください。逆向きに走りたい場合は「ルート」→「ルート反転」を使います。

  2. 出発前にオフライン準備を確認する

    GPXを読み込むと、ルート周辺の地理院地図などの準備が自動的に始まります。「ルート」→「オフライン準備状況」で進捗を確認できます。圏外へ出る予定なら、通信できる場所で完了を待ってください。

  3. 「GPXルート走行開始」を押す

    プレビューから開始します。読み込んだGPXが待機中なら、「ルート」メニューの同名の項目からも開始できます。

  4. 地図のGPX線・進捗・ターン案内を確認して走る

    GPXの道筋を辿る機能であり、目的地への最適経路を検索する機能ではありません。曲がり角の案内だけに頼らず、地図上の線も確認してください。

GPXファイルを他のアプリからGPX Compassへ共有して読み込むこともできます。

「ゴール地点までナビ」は、GPXを辿る開始ボタンではありません。
これは現在地からGPXのゴール地点への道路経路を別に検索する機能です。GPXどおりに走るには「GPXルート走行開始」を選びます。

圏外で使うときの注意

GPX案内にはご自身のAPIキーは不要ですが、地図の取得には通信が必要です。保存済みの地理院地図は圏外でも使えます。「地図」で「地理院標準」を選ぶと表示を確認できます。「自動」では圏外時に地理院地図へ切り替わります。

保存されるのは読み込んだルートの周辺であり、全国の地図ではありません。未取得の範囲は表示できません。また、Google地図のオフライン保存機能ではなく、目的地ナビの経路検索もオフラインでは利用できません。

02 · 「ナビ」メニュー

任意の目的地へナビゲーションする

GPXを読み込まなくても使える、もう一つの機能です。現在地から選んだ目的地までの経路をGoogle Routes APIで検索します。インターネット接続と、ご自身で用意したRoutes APIキーが必要です。

初回だけ：Routes APIキーを設定する
  1. Google Cloudでプロジェクトと請求先を設定し、Routes APIを有効にしてAPIキーを作成します。手順はGoogle公式のRoutes APIセットアップガイドを参照してください。
  2. キーには利用制限を設定してください。APIの制限はRoutes APIを対象とし、Androidアプリの制限に必要なパッケージ名とSHA-1は、次のアプリ内設定画面で確認できます。
  3. GPX Compassで「地図」→「目的地ナビ / Routes API」を開き、「Routes APIキー」に入力して「保存」を押します。
  4. 「APIキー: 登録済み」を確認し、同じ画面の「移動モード」で用途に合う「自動車」または「自転車」を選びます。

キーの設定場所は「ナビ」ではなく「地図」メニューです。APIキーは他人に共有したり、公開したりしないでください。

APIの利用料金が発生する場合があります。Google側の料金・利用上限を確認してから使ってください。Routes APIの使用量と課金

地図から目的地を選ぶ

  1. 「ナビ」→「地図から選ぶ」を開く

    地図を動かし、目的地を画面の照準に合わせます。

  2. 「ここへナビ」を押す

    経路検索が成功すると、その目的地への案内が始まります。

  3. 終了するときは「ナビ」→「ナビを中止」

    記録も行っている場合、ナビの中止と走行記録の終了は別の操作です。

一度使った行き先は「最近の目的地」から選べます。「お気に入り」も利用できます。

Googleマップで探した場所へ向かう

Googleマップアプリで場所を選び、「共有」の送信先にGPX Compassを選ぶ方法もあります。共有内容を目的地として認識できると、GPX Compassで経路検索が始まります。APIキーを先に設定し、停車中に操作してください。

GPX Compassの「ナビ」メニュー自体に、住所や施設名を入力する検索欄はありません。地図上で選ぶか、Googleマップなどから場所を共有してください。

HOW THEY WORK TOGETHER

GPXと目的地ナビを使い分ける

例：GPXのスタート地点まで行ってから、コースを走る

  1. GPXを読み込む

    「ルート」→「GPX読込」でコースを用意します。

  2. 「ルート」→「スタート地点までナビ」

    現在地からスタート地点までの道路経路を検索します。この部分はRoutes APIを使うため、APIキーと通信が必要です。

  3. 到着したら「ルート」→「GPXルート走行開始」

    ここからはGPXの道筋を辿ります。目的地ナビの終了や到着だけでは、GPX案内は自動的に再開しません。

GPX案内中に別の目的地へのナビを始めると、GPXは消えずに待機状態になります。GPXへ戻りたいときも「ルート」→「GPXルート走行開始」を選んでください。

「スタート地点までナビ」「ゴール地点までナビ」は「ルート」メニュー内にありますが、どちらも地点への経路検索です。「ルート」内にあるからAPIキー不要、というわけではありません。

OPTIONAL

走行を記録する

道案内と走行記録は別の機能です。走った軌跡を残したい場合は、メニュー下部の「記録開始」または「走行記録も開始」を押してください。案内なしで記録だけ行うこともできます。

終了時はメニュー下部の四角い停止アイコン（「セッションを終了」）を押し、画面の確認に従って記録を終了・保存します。案内と記録の両方が動作している場合は、終了する対象を選べます。保存済みの記録は「走行ログ」で確認・共有できます。

画面を閉じるだけでは案内や記録の終了になりません。走行を終えたら、アプリ内の終了操作と通知の状態を確認してください。

HELP

困ったとき

「APIキー: 未登録」と表示されます。GPX案内も使えませんか？

GPX案内とGoogle地図の表示には、ご自身のRoutes APIキーは不要です。そのまま「ルート」からGPXを読み込んで使えます。登録が必要なのは目的地への経路検索です。

地図が表示されません

通信状態と「地図」の表示設定を確認してください。Google地図だけ表示できない場合、Routes APIキーの入力では解決しません。「地理院標準」へ切り替えて確認できますが、未保存の地図の取得には通信が必要です。

目的地ナビを開始できません

現在地が取得できているか、インターネットに接続しているか、「地図」でAPIキーを保存したかを確認してください。認証エラーの場合はGoogle Cloud側のRoutes APIの有効化、請求設定、キーの制限を確認します。利用上限に達した場合はGoogle Cloud側の利用状況を確認してください。

目的地ナビを終えたのに、GPXの案内が始まりません

GPX案内への切り替えは手動です。「ルート」→「GPXルート走行開始」を選んでください。読み込んだGPXは待機状態で残っています。

GPXの線を外れたら、自動で別の道を検索しますか？

GPX案内は、元のGPXを辿るためのものです。逸脱時に自動で別の道路経路へ置き換えるものではありません。安全な場所で地図を確認してください。「寄り道モード」と「逸脱地点までナビ」もありますが、後者の経路検索にはRoutes APIキーと通信が必要です。

音声案内が聞こえません

「音声案内」の設定、端末の音量、Bluetoothの接続先・音声出力を確認してください。端末の読み上げ機能の設定によっても音声の出方が変わります。走り始める前に停車中の状態で確認してください。
